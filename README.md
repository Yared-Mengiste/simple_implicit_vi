# Implicit VI on a Banana Distribution

Open [Simple_Implicit_VI.ipynb](Simple_Implicit_VI.ipynb) in Jupyter or Google Colab
and select **Run all** on CPU. It compares Gaussian VI, adversarial DRE, and SIVI.

[Findings_One_Page.pdf](Findings_One_Page.pdf) summarizes the mechanics, results,
and trade-offs. 

For local dependencies: `python -m pip install -r requirements.txt`.
